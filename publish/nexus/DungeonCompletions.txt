[size=5][b]Dungeon Completions[/b][/size]
A small tag next to each dungeon's name, with the number of times you have completed it.

[list]
[*]Open the combat areas menu: every dungeon in the list has the tag after its name, and so does the panel of the dungeon you selected.
[*]A dungeon you have never finished shows 0. Ordinary combat areas get no tag.
[*]The number is the game's own statistic: every completion since the character was made, not since you installed the mod.
[/list]
Useful for tasks that ask for a number of completions, and for seeing at a glance which dungeons you have never done.

No settings, no files.

[size=4][b]Install[/b][/size]
[list=1]
[*]Install the [url=https://www.nexusmods.com/melvoridle2/mods/2]Melvor Mod Loader[/url] (0.1.3 or newer).
[*]Extract this zip into the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files. The file ends up as [font=Courier New]mods\DungeonCompletions\DungeonCompletions.dll[/font].
[*]Start the game.
[/list]
To update, extract the new zip over the old one.

[size=4][b]Uninstall[/b][/size]
Delete the folder [font=Courier New]mods\DungeonCompletions[/font]. Nothing in your save is changed.

[size=4][b]About[/b][/size]
Made for game version 0.11.6-alpha.1 with Melvor Mod Loader 0.1.3. The game is in early access: an update can break the mod until it is rebuilt. It then switches itself off and says so in MelvorModLoader.log; the game and your other mods keep running.
It uses the game's own textures, fonts and colours, so it looks like part of the game. It gives no items, XP or bonuses.
