[size=5][b]Kills in Combat[/b][/size]
A small tag next to the name of the enemy you are fighting, with the number of times you have killed it. That is the whole mod.

[list]
[*]It is on the combat screen, right after the enemy's name. Hover it for the sentence.
[*]It follows the fight: change enemy and the number changes with it.
[*]The number is the game's own statistic for that enemy: every kill since the character was made, not since you installed the mod, and kills made while the game was closed are in it.
[/list]
Useful for tasks that ask for a number of kills, and for knowing how unlucky you are with a rare drop.

No settings, no files.

[size=4][b]Install[/b][/size]
[list=1]
[*]Install the [url=https://www.nexusmods.com/melvoridle2/mods/2]Melvor Mod Loader[/url] (0.1.3 or newer).
[*]Extract this zip into the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files. The file ends up as [font=Courier New]mods\KillsInCombat\KillsInCombat.dll[/font].
[*]Start the game.
[/list]
To update, extract the new zip over the old one.

[size=4][b]Uninstall[/b][/size]
Delete the folder [font=Courier New]mods\KillsInCombat[/font]. Nothing in your save is changed.

[size=4][b]About[/b][/size]
Made for game version 0.11.6-alpha.1 with Melvor Mod Loader 0.1.3. The game is in early access: an update can break the mod until it is rebuilt. It then switches itself off and says so in MelvorModLoader.log; the game and your other mods keep running.
It uses the game's own textures, fonts and colours, so it looks like part of the game. It gives no items, XP or bonuses.
